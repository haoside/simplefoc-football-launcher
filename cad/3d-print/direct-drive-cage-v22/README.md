# Direct-Drive Cage v22 — 径向电机直驱笼体（参考结构最终修正）

> 参考特写确认: **电机轴线沿径向（与发射管轴成 90°）**，转子壳圆周正切于中央球孔缘，
> 壳面凸入孔内压球，旋转切向速度沿管轴把球射出。
> 修正历史: v20 径向但摇篮形态错 → v21 误改轴向 → **v22 正确**。

## 几何核心

```
中央球道孔  φ200 (球φ220挤过, 单触点预紧10mm... 实际壳面凸入孔缘6mm)
转子滚动面  φ79 (6374壳φ63 + PU套8mm)
电机轴      径向, 120° 均布 (12点/4点/8点)
壳心分布半径 R_C = 100 - 6 + 39.5 = 133.5mm
弧形座      内弧φ64 (贴壳), 150°包角, 从外侧抱住电机, 开口朝孔侧
```

## 零件

| 文件 | 数量 | 说明 |
|---|---|---|
| `stls/spider_body_v22.stl` | 1 | 主笼体: 中央孔环(φ200×60, 两端翻边) + 3×径向弧座 + 连接梁 + 座端面 M3 沉孔 |
| `stls/motor_snap_ring_v22.stl` | 3 | 电机卡环: 中心过轴孔 φ24, 3×M3 锁入座端面 |

渲染: `render_v22.png` — TOP 视图三转子径向 + 壳面切孔缘，与参考照片构图一致。

## 装配

1. 电机套 PU 环，从外侧轴向插入弧座（定子端盖朝外）
2. 盖 `motor_snap_ring_v22`，3×M3 锁入座端面沉孔
3. Hall 线从座开口(孔侧)引出
4. 中央孔两端接导球管（复用 SHORT_GUIDE_TUBE），球沿 Z 轴通过

## 打印

- 主笼体孔环轴向平放（Z 朝上），弧座区局部需支撑
- PETG，层高 0.28，壁 4 圈，填充 40%，座区 60%
- 约 380g

- [x] 双零件 watertight

## 备注

- PRELOAD=6mm 为壳面凸入孔缘量；总预紧由孔径 φ200 与球 φ220 的差配合决定，
  首装后按 PU 硬度微调孔径 (±2mm)。
- 若需更强夹持，可把孔径缩到 φ196 (PRELOAD=8)，仿真模型同步改 BORE_R。
