# Direct-Drive Cage v24 — 杯状电机座一体化笼体（含轴孔与定子固定细节）

> 参考 CAD 截图确认: 座为**完整圆杯**（非弧瓣），外端面实心、中央过轴孔，
> 电机整体藏于杯内，轴朝外穿出；座与发射管一体成型。
> 拓扑继承 v23（径向电机/壳凸入孔），新增固定细节。

## 结构定义

```
        ┌─ 单件打印体 ─────────────────────────┐
        │  中央发射孔环 φ200×56                 │
        │    ↑ 孔壁开窗, 转子壳面凸入夹球        │
        │  3× 圆杯座 (120°, 径向):              │
        │    - 完整圆筒 内φ64 × 长81            │
        │    - 外端面厚7, 中央过轴孔 φ8.7        │
        │    - 端面 4×M3.2 螺丝孔 @PCD30        │
        │      (轴向拧入电机定子法兰)            │
        │    - 法兰沉台 2.2深 (定位)             │
        └──────────────────────────────────────┘
```

- 电机装配向：定子端朝外（轴+线从外端面出），转子壳朝孔侧
- 壳心分布半径 R_C = 100 − 6 + 39.5 = **133.5**
- 定子被端面螺丝夹紧 → 转子壳旋转压球
