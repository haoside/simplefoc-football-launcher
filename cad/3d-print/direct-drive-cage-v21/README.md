# Direct-Drive Cage v21 — 平板蜘蛛笼体（严格复现参考结构）

> 参考: YouTube `WQlTYPqzlNI` @3:23 — 橙色平板笼体, 三电机轴线**平行**于中央孔轴,
> 电机壳嵌在板内、内切于孔缘, 球从孔中挤过被三个转子壳摩擦加速。
> 取代 v20（v20 误将电机做成径向摇篮, 与参考不符）。

## 与 v20 的结构差异（复现修正）

| 项 | v20 (错误) | **v21 (复现)** |
|---|---|---|
| 笼体形态 | 深筒+径向摇篮 | **平板 (26mm 厚)** |
| 电机轴线 | 径向 (垂直孔轴) | **平行孔轴** ✅ |
| 电机固定 | 弧座包角+压盖 | **C形座嵌入+顶部压环×3 M3** |
| 球道 | 圆筒内孔 | **平板中央孔 φ200** |

## 几何核心（复现推导）

```
球 φ220, 单触点预紧 10mm → 球道孔 φ200
转子滚动面 φ79 (6374壳φ63 + PU套8mm)
电机圆心分布半径 R = 100 + 39.5 = 139.5mm
三转子内切于孔缘 → 每转子的接触弦与孔相切
```

## 零件

| 文件 | 数量 | 说明 |
|---|---|---|
| `stls/spider_plate_v21.stl` | 1 | 平板笼体: 三叶轮廓 + 中央孔 + 3×C形电机座(200°包角开口朝外) + 叶间 M5 安装孔 |
| `stls/motor_retainer_v21.stl` | 3 | 电机压环: φ80×6, 3×M3 沉孔, 锁住电机端面于板面 |

渲染: `render_v21.png`（TOP 视图与参考图构图一致）

## 打印

- PETG / PA-CF, 平放打印（无需支撑, C形座开口朝外自然桥接）
- 层高 0.28 / 壁 4 / 填充 40%（电机座区 60%）
- 主板约 320g

## 装配

1. 电机套 PU 环后从板**下方**轴向插入 C 形座（开口让线缆引出）
2. 端面盖 `motor_retainer_v21`, 3×M3 锁入板面沉孔
3. 三电机 Hall 线统一从开口侧出, 沿叶臂走线
4. 球从中央孔 φ200 通过, 三转子预转即发射
