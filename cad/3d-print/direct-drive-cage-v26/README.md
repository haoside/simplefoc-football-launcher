# Direct-Drive Cage v26 — 切向电机耳板笼体（参考CAD最终复现）

> 参考 CAD（2026-08-24 14:28 截图）+ 视频帧确认的最终拓扑:
> **电机轴线与孔圆周相切**（切向布局），耳板从孔环径向长出、板上过轴孔，
> 转子壳穿墙伸入孔内，壳面切向速度沿管轴把球射出。

## 版本演进（历次纠正）

| 版本 | 电机轴线 | 结果 |

| v21 | 轴向（∥管轴） | ❌ 方向错 |
| v22–v24 | 径向 + 杯座 | ❌ 座形态错、与参考 CAD 不符 |
| **v26** | **切向（⊥半径）** | ✅ 与参考 CAD 一致 |

## 几何核心

```
中央发射孔环   内φ200 × 外φ236 × 长64
壳心分布半径   R_C = 100 − 6 + 39.5 = 133.5 (切向轴过此点)
耳板           厚16(切向) × 宽34(轴向), 从环壁长到 R178
               R_C 处过轴孔 φ8.7, 端部 M3 吊装孔
壳穿墙窗口     轴向长56, 壳面凸入孔内 PRELOAD=6mm
```

**力学**: 切向布局下壳面接触点速度严格沿管轴 → 球沿管轴射出；
三轮差速 → 侧旋（Magnus 弧线，见 `sim/odrive_launch_sim_v1.py`）。

## 装配

1. 电机套 PU 环，轴沿切向穿入耳板轴孔（定子在环外）
2. 转子壳对准环壁窗口伸入孔内，壳面凸入 6mm
3. 轴端用 e-clip 或压板轴向定位（细节后续版本）
4. 孔两端对接导球管，球沿管轴通过
