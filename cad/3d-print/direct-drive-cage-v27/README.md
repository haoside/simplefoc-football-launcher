# Direct-Drive Cage v27 — 切向裸壳 + 轴承耳板 + MKS XDRIVE Mini 基座

> Owner 指定修正: **电机不套 PU 环**（裸 6374 壳 φ63 直接做摩擦面，不加尺寸、保一体化）。
> 在 v26 切向拓扑上新增：轴承固定轴板 + MKS XDRIVE Mini 驱动基座（AS5047 支持）。

## 关键变更（vs v26）

| 项 | v26 | **v27** |
|---|---|---|
| 摩擦面 | φ79 (壳+PU套) | **φ63 裸壳** |
| 壳心分布半径 R_C | 133.5 | **123.5** (=100−8+31.5, 凸入加深到8mm) |
| 耳板轴孔 | φ8.7 光孔 | **φ16.35 轴承通孔 (625ZZ)**, M3长螺丝+垫圈夹固 |
| 驱动器 | 无位 | **每电机一块 XDRIVE Mini L型基座** |

## MKS XDRIVE Mini 集成

- 板体实测（官方 STEP）：**66.3 × 58.2 mm**；基座内腔 68×60 留间隙
- **一块 XDRIVE = 双轴** → 3 电机用 **2 块板**（#1: axis0+axis1，#2: axis0；ghost axis1 设 `can_node_id=63` listen-only 防总线冲突）
- 固件锁 **v0.5.1**（v0.5.6 会砖）；配置用 odrivetool + 仓库 my_config.txt
- 极对数：6374 = 14 极 → `pole_pairs = 7`

## AS5047 支持

- 每块基座一角预留 **20×20 AS5047 小板位**（2×M2 孔）
- 编码器磁铁装电机轴外端面，小板正对磁钢，**气隙 1~2mm**
- 读数走 I2C/SPI 回 ESP32-S3 主控
