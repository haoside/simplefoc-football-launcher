# Direct-Drive Cage v20 — 6374 电机支架（V2 直驱方案）

> 参考结构：三电机直驱发射器（电机壳即摩擦轮）。
> 生成脚本：`gen_v20.py` → `stls/`

## 关键尺寸

```
球道内径      224 mm   (球 φ220, 单边间隙 2mm)
滚动面直径    79 mm    (6374 壳 φ63 + PU 套 8mm)
摇篮包角      >105°    (开口朝球道, 自对中)
摇篮弧半径    39.9 mm  (φ79 + 0.4 打印间隙)
滚动面侵入球道  2 mm   (= 预紧基准, 可用压盖再收紧)
笼体总包络    ~380 × 380 × 170 mm
端板          φ150, PCD 135, M5 ×6
```

## 装配顺序

1. 三个 6374 电机套上 PU 环（铝箍热套+环氧, 见 MECH_REDESIGN_ODRIVE_V2_DIRECT_DRIVE.md）
2. 转子组件从摇篮开口压入弧座（过盈自对中, 定子端盖朝外）
3. 扣上 `cradle_clamp_v20`, M6 螺柱穿出 → 预紧力由螺母行程控制
   - 目标单轮法向力 ~300N（对应压紧 10~12mm, 沿用仿真标定）
4. 两块端板用 M5×6 锁到螺柱上, 形成闭环框架
5. 整体经端板 φ30 毂装入俯仰轴

## 打印参数建议

- 层高 0.28mm / 壁 4 圈 / 填充 35%（摇篮区 60%）
- 方向：主笼体**轴向竖直打印**（球道孔朝上），摇篮无需支撑
- 主笼体预计 ~450g PETG
