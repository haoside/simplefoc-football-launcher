# MECH_REDESIGN_ODRIVE_V1 — 机械结构重建方案（ODrive 版）

> 背景：Owner 决策切换 ODrive 后，原“6374 外转子嵌入发射筒壁”的三角嵌入式结构需要重建。
> 本文给出 2 个候选结构 + 1 个推荐方案，并回答电机数量问题。
> 配套仿真：`sim/odrive_launch_sim_v1.py`、`widgets/odrive_sim_3d.html`

## 1. 电机数量意见（Owner 提问的直接回答）

**建议：3 台 → 保持 3 台，但换布局；不建议加到 4~6 台。**

理由：

| 方案 | 轮数 | 球速上限* | 控制自由度 | 机械复杂度 | 结论 |
|---|---|---|---|---|---|
| 双轮上下 | 2 | ~28 m/s | 无侧旋 | 低 | 无法弧线，否决 |
| **三轮 120°** | 3 | ~30 m/s | 俯仰+侧旋+自转 | 中 | ✅ 推荐 |
| 四轮 2×2 | 4 | ~35 m/s | 全向旋+更快 | 高（4 套 ODrive） | P1 再说 |
| 六轮 | 6 | ~40 m/s | 同上 | 过高 | 否决 |

\* 上限按 6374@3000rpm、110mm 摩擦轮线速度 ≈17m/s ×2 加速段估算。

**关键论据：**
- 训练目标 `15~20m 边路长传` → 需要球速约 `18~25 m/s`，三轮已覆盖
- 弧线球 = 左右轮差速；上下俯仰 = 俯仰架机械调角。三轮已给足控制面
- 每多一台 ODrive S1 = +¥1400 + 一路 CAN + 散热，P0 收益不成比例
- 三轮 120° 是现有 RPM mixer / CURVE_BALL_CONTROL 文档的数学前提，保持 3 台可最大化复用已有软件资产

## 2. 结构重建核心变化

### 旧结构的问题（为什么必须重建）

```
旧: 发射筒壁开孔, 6374 外转子(φ63)嵌入筒内
 ❌ 筒壁开大孔后刚度崩塌, 三个孔互相削弱
 ❌ 电机轴悬臂伸入筒心, 摩擦轮装在轴端, 挠曲大
 ❌ ODrive S1 (92×62mm) 比 B-G431B 大得多, 塞不进原电机腔
 ❌ 维修: 换电机要拆筒体
```

### 新结构原则

1. **电机外置化** — 电机不再嵌筒，改为筒外侧法兰安装，摩擦轮通过轴伸入
2. **模块化轮组** — 电机+摩擦轮+张紧机构做成独立"轮组模块"，整机 3 个相同模块
3. **可调预紧** — 每个轮组带铰链+丝杠预紧，压紧量 5~15mm 可调（沿用 WHEEL_DIAMETER_RULES）
4. **ODrive 远置** — 功率板不随机头振动，放底盘电气舱，短粗动力线 + Hall 延长线

## 3. 推荐结构：外置三轮铰接预紧式（Candidate A）

```
            俯仰轴
              ╳ ──────────────
             ╱ ╲
      ┌────╱───╲────┐
      │   ╱ 发射 ╲   │   ← 导球锥 + 短导引管(复用 SHORT_GUIDE_TUBE)
      │  ▼  筒口  ▼  │
      │ WheelA(12点) │ ← 轮组模块×3, 铰接臂+丝杠预紧
      │ W C   ○   W B│
      └──┴─────────┴──┘
        6374 + 摩擦轮 φ110
        ODrive S1 → 底盘电气舱
```

### 轮组模块构成（×3 相同）

| 子件 | 规格 | 说明 |
|---|---|---|
| 电机 | 6374 170KV, Hall | 保留现有采购 |
| 摩擦轮 | φ110×40mm PU 包胶, 铝芯 | 3000rpm ≈ 17.3m/s 线速度 |
| 安装臂 | 6061 铝板 8mm, 铰接 | 激光切 + 折弯 |
| 预紧丝杠 | M8×1.0 + 碟簧 | 压紧量 5~15mm 连续可调 |
| 防护罩 | PC 透明 3mm | 每轮独立 + 整筒围板 |
| 接口 | XT90 动力 + 6P Hall 延长 | 至电气舱 ODrive |

### 与旧文档的约束继承

- ✅ 120° 均布、三轮切向偏置 → `RPM_MIXER_120DEG` 公式不变
- ✅ 球 φ220 / 范围 90~130mm 轮径 / 预紧 5~15mm → `WHEEL_DIAMETER_RULES` 不变
- ✅ 导球短管 → 复用 `SHORT_GUIDE_TUBE_V1`
- 🔄 电机固定 → 由"筒壁开孔嵌入"改为"外置臂法兰 4×M4"
- 🔄 发射筒角色 → 只承担"球通道 + 轮组安装骨架"，不再承担电机定位

## 4. 备选结构（Candidate B）：双上夹轮 + 单下托轮

上 2 轮左右对称夹球（主要压力与速度），下 1 轮托底（控制后旋量）。

- 优点：入射对中性更好，上下旋更直觉（发球机主流方案）
- 缺点：侧旋弱于三轮 120° 切向方案；俯仰需整机俯仰架
- 定位：若 A 实测弧线量不足（侧旋 <6 rps），P1 切换此方案

## 6. 安全设计（继承 + 强化）

- 物理急停：硬断 ODrive enable + CAN 广播 ESTOP（双通道）
- 每轮独立 PC 防护罩 + 出球口挡帘
- 上电默认 IDLE：ODrive `axis.state = IDLE`（自由态）
- SPINUP 前置条件：球在位（光电对射）+ 防护罩磁控开关闭合 + 急停未触发
- 出球后 COOLDOWN 2s 防连发

## 7. 验证路径（三维仿真先行）

1. 三维交互仿真：`widgets/odrive_sim_3d.html`（几何干涉 / 轮球接触 / 出球参数）
2. 弹道复算：`sim/odrive_launch_sim_v1.py`
3. 3D 打印 1:1 铰接臂样件，手转验证预紧行程
4. 单轮组空载跑合（与 ODrive M1 阶段并行）
5. 整机低速 ≤1000rpm 射球 → 逐步提转速
