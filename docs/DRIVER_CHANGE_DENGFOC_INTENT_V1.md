# 驱动板变更意向记录 — DengFOC 评估 (未定案)

> 状态：**意向记录，未定案**。Owner 2026-08-25 提出将驱动板切换为
> 灯哥开源 DengFOC V3.0 (github.com/ToanTech/Deng-s-foc-controller)。
> 经匹配度分析存在关键功率缺口，决策留待实测后定。

## 1. DengFOC V3.0 规格摘要

| 项 | 值 |
|---|---|
| 主控 | ESP32 (lolin32 lite, 板载) |
| 软件栈 | SimpleFOC / DengFOC 库, Arduino |
| 尺寸 | 56×39mm |
| 输入电压 | 12–24V ✅ |
| 支持电机数 | **2 路/板** |
| 单路功率 | 120W（双路共 240W）|
| **电流检测上限** | **3.3A** ⚠️ |
| 编码器支持 | IIC/ABI/PWM/SPI/HALL (AS5047/5600 等) ✅ |
| 成本 | 低 (~¥200 级成品含 ESP32) |

## 2. 与本项目需求的匹配度

| 需求项 | 需求值 | DengFOC | 判定 |
|---|---|---|---|
| 驱动 6374 发射 | 峰值 20~40A/路, 瞬时 ~500W | 检测上限 3.3A, 120W | ❌ 数量级差距 |
| 目标电机定位 | 动力级 BLDC | 云台电机 | ❌ 设计对象不同 |
| AS5047 支持 | 需要 | 原生支持 | ✅ |
| 24V 系统 | 是 | 是 | ✅ |

**结论：DengFOC 不能直接驱动 6374 完成实弹发射。**

## 3. 三条候选路径（待实测定案）

### 方案 A — DengFOC 主控 + 外置大电流功率级
DengFOC 的 ESP32/SimpleFOC 输出 PWM 至外接 DRV8353 级功率板驱动 6374。
- ✅ 保留 SimpleFOC 生态与低成本主控；保留现有性能
- ❌ 回到"自研功率级"路线——这正是当初切 ODrive/XDRIVE 要规避的硬件风险
- 需恢复 `P0B_HIGH_CURRENT_DRIVER_CANDIDATES_V1.md` 的 DRV8353 候选评估

### 方案 B — 换电机适配 DengFOC
放弃 6374，改用云台/中型电机（如 5010 360KV ×3）直驱。
- ✅ 全链路 SimpleFOC + DengFOC，成本最低、最轻量
- ❌ φ63 裸壳摩擦面随之改变 → 机械结构 (v26/v27) 与仿真全部重算
- ❌ 球速上限大幅下降，20m 长传目标大概率不达

### 方案 C — 分工并用（当前架构不变）
DengFOC 仅用于 P0-A 低速台架验证（算法/编码器链路），
实弹功率链维持 XDRIVE Mini ×2 方案。
- ✅ 零风险，两套板各司其职
- ❌ 多一块板的成本；控制代码需维护两套接口

## 4. 实测定案所需数据

无论走哪条路径，先测：

1. [ ] DengFOC 实际持续输出能力（官方 120W 标称的可持续性、温升曲线）
2. [ ] 6374 在发射工况的真实电流峰值（台架实测，验证仿真 ~40A 估算）
3. [ ] 若方案 B：候选云台电机 (5010/5008) 的壳径、KV、堵转扭矩 → 重跑 `sim/odrive_launch_sim_v1.py`
